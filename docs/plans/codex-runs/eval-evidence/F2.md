**Evidence:** live `/api/skills/catalog` responses under simulated unavailable states; `/api/skills/run` responses.

**Procedure:** Loaded catalogue with missing/corrupt/empty Codex catalogue, missing/corrupt/empty `opencode models` output, missing OpenRouter curated catalogue; simulated absent `codex`/`opencode` executables (not on PATH and not at the known install locations); tried otherwise-valid requests per provider.

**Observed:**
- Claude options always work regardless of provider catalogue state (retained).
- Missing/corrupt catalogue → that provider's `provider_available: false` with a reason; `provider_models` empty for that provider; no model IDs invented; explanation available via `provider_unavailable_reason`.
- Codex cache unreadable → `codex: false`, reason "Codex catalogue unreadable: ...".
- `opencode` absent from PATH → `opencode: false`, reason "opencode executable not on PATH"; a run request records status `failed` with that message.
- `codex` absent from PATH → `codex: false`, reason "codex executable not on PATH"; a run request is rejected with 400 and that message before anything launches.
- OpenRouter cache missing → `openrouter: false`, reason.
- No executable state ever falls back to Claude, invents model IDs, or shows credentials.

**Result:** pass — Claude retained, missing catalogue does not invent IDs, a missing executable is reported per provider (400 before launch for Codex, failed run with actionable output for OpenCode), no fallback, no credentials.
