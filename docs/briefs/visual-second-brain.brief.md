# Workspace map surface brief

- **Target:** visual-second-brain/visual-second-brain.html; `/workspace-map/` and the dashboard's Workspace map iframe.
- **Mode:** Operate.
- **User success:** Find a workspace file by topic, folder, query, type, or date; inspect it and use the permitted file actions.
- **Identity:** Preserve incumbent Orizuru paper, vermilion, ink, Inter, and path/numeric monospace. See visual-second-brain/DESIGN.md.
- **Approved enhancement:** Folded Atlas — one real folded-paper mesh beside the topic index, with bounded movement and brief topic-pose changes. Keep conventional search/results primary.
- **Native affordances:** Standard HTML controls, current keyboard shortcuts, file details and focus restoration. Decorative geometry does not become navigation.
- **Responsive boundary:** A wide-screen sculpture rail from 1100px; compact static fold on smaller index views; no narrow-screen sculpture in results/details.
- **Hard constraints:** Read-only curated snapshot; local assets only; unchanged schema, privacy and file authorization; no build/install needed to run; static fallback; live reduced-motion support; rendering pauses when hidden/offscreen.
- **Acceptance:** docs/plans/visual-second-brain-overdrive/eval.md, approved 2026-11-12. The static mockup is a composition study, not proof of GPU behavior.
