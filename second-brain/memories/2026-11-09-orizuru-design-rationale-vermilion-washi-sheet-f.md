Orizuru design rationale (dashboard-app/DESIGN.md): replaces the former "Atmospheric Glass" world — one uncut sheet of vermilion washi becoming a crane through discrete numbered folds. The career is one uncut sheet; every task is a fold; weekly routine maps to fold steps; gold dot marks today's active position; finished shape carries every crease — files recoverable, every fold unmade. Maps 1:1 to product truth: dashboard and source files can never disagree; a checked box is a fold made; details preserved in file history; nothing welded shut. Fold-state vocabulary → task states: flat/unchecked (empty crease-tick square); creased/checked sterile (folded ink-checked corner); collapsed/completed/task-done (dimmed row); based/blocked (halts in numbered column); locked/completed item (gold step-dot); finished/done shipped (crease line drawn full); recoverable/every toggled file (atomic write, git history). Visual authority: palette — vermilion washi ground #b3212e with visible kozo fiber; crease lines faded fold-white #f4ead8; one gold dot #c9a227 active step; notes sumi black ink #171512; content faces undyed washi #f8f1e3 so sumi ink stays readable — ink on white folds, never dye. Materials — kozo-fiber washi texture layered CSS gradients + faint feTurbulence tooth; no external images, no glass, no glossy gradients. Type — Inter beside JetBrains Mono step numbers and crease-count figures. Composition — seven (eight with Money) pages are faces of the sheet; week's routine numbered fold column in left margin; whole dashboard one continuous sheet. Signature interaction: toggle — one click folds/unfolds a task; fold-state changes atomically; every fold recoverable; gold dot moves with toggle. Fold-map focus — hover/focus on numbered weekly step opens paper-card preview of related task ledger and progress; arrow keys traverse; Enter/Space/click hold context; without JavaScript numbered weekly list is complete fallback. Motion grammar: fold/unfold discrete snap, no continuous spatial animation; progress bars ride quiet crease (width 0 → data-width, one sanctioned animation); pages unfold tiny non-spatial fade; fold-map focus short opacity/state transition; prefers-reduced-motion removes transitions preserving selected state and hierarchy. Responsive: desktop — numbered fold column (1..N) left, pages as faces right; mobile (≤900px) — fold steps horizontally-scrollable numbered column; each page full-width face. Accessibility: fold lines + numbered margin column carry state independently of color; gold dot redundant with fold number; contrast held on washi (ink on undyed washi, fold-white on vermilion); WAI-ARIA tabs, focus-visible rings, skip link, reduced-motion. Anti-goals: glass/gradient panels (old world), neon/dark command consoles, external image assets for data, spatial/continuous animation — all fight one-sheet thesis; sheet calm, flat, honest. Token map: --vermilion #b3212e ground/masthead/column; --vermilion-deep #8e1a24 shadowed folds/page bg; --fold-white #f4ead8 crease lines/nav active; --paper #f8f1e3 unfolded faces; --gold #c9a227 active step dot; --sumi #171512 ink; --washi-fiber layered gradients paper tooth. Metrics typography: Inter chart captions 14px/600, legends/axes 12px/500; JetBrains Mono identifiers and measured values 12–13px; tabular numerals stable during refresh; sparkline ranges 12px with 1.5 leading; long workload/device identifiers wrap, no truncation; percentage axis reserves space for full 100% label at narrow widths. Metrics color: color concentrated in data/selected controls, not panel decoration; CPU/send vermilion; memory/receive blue; capacity plum across card bar/sparkline/legend/history; disk reads teal, writes deep ochre #805b0a dashed stroke; green up/healthy/safe capacity; ochre/red warning/critical; ranking selection uses same CPU/memory ink as bars; solid/dashed/dotted line distinctions retained; unknown severity hatched; every status named in text.
