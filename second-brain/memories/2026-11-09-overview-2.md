- [stated] SalsaSegura.com is a salsa dance community platform with both web and mobile components
- [stated] Serves multiple stakeholders: event promoters who submit events, and community members who browse and engage with them
- [stated] Broader goal is to become a trusted hub for the salsa community, which influences product decisions (e.g. protecting the platform's reputation with event organizers when adding social features)
- [stated] Backed by Supabase for auth, Postgres database with RLS, real-time subscriptions, and storage
- [stated] Web app exists (framework not specified); parallel mobile app planned in React Native with Expo, sharing the Supabase backend
- [stated] Language: TypeScript
- [stated] Mobile calendar libraries: `@howljs/calendar-kit` (day/week views), `react-native-calendars` (month view)
- [stated] Monorepo-style structure with `/shared`, `/web`, and `/mobile` directories
- [stated] Reusable `useSupabaseEvents` hook with real-time subscriptions lives in the shared layer

## Current state

- [stated] Following a phased weekly roadmap with explicit time estimates per feature
- [stated] Completed or in progress: authentication (Week 5), moderation dashboard (Week 6), RSVP functionality (Week 18), Favorites (Week 19)
- [stated] Most recently planned feature is a two-phase matching system
- [stated] Phase A — "Discover Mode" (Weeks 19–20): event swiping
- [stated] Phase B — "Dance Connect" (Weeks 27–34): people matching, in four sub-phases — match profiles, swipe/match logic, realtime chat, and a safety/moderation layer
- [stated] `MATCHING_FEATURE_GUIDE.md` documents the full matching plan: annotated SQL schema with RLS policies, legal/community trust checklists, success metrics, and roadmap timing

## On the horizon

- [stated] Launch the mobile app (React Native + Expo) on shared Supabase infrastructure
- [stated] Execute Phases A and B of the matching feature per the documented roadmap
- [stated] Phase B safety and moderation layer — a non-negotiable pre-launch requirement
- [stated] Mobile-specific features to explore: push notifications, offline support, image caching, location-based filtering, real-time event updates
