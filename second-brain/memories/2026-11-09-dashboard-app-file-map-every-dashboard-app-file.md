dashboard-app file map (from CLAUDE.md): app.py — REALMS config, parsers, build_context(), routes; add a realm or context data. interview_editor.py — line-targeted writes to interviews/job-applications.yml (status/priority, next action, timeline signal, interview_notes / interview_questions / interview_preparation, new application); re-parses as a guard. triage_jev.py — Triage inbox card: Jev answers two questions per unchecked ## Inbox item (does a ### section fit, which one); decide() holds 0.7/0.3 Noul and 0.5 Choice thresholds turning answers into file-or-hold; sends item text plus section headings only — never section contents. leads_jev.py — job leads second opinion: one Jev question per requirements: line on a tracker row, judged against the resume variant that row names; score() counts met (>=0.7) / thin / missing (<=0.3) into apply / gap story / skip; email and phone stripped from every request, nothing written. templates/index.html — thin shell: head, nav tabs, {% include %} list, run-output and interview-mode dialogs. templates/interview_sheet.html — standalone printable prep sheet (print CSS). templates/pages/<tab>.html — one file per tab: overview, today, education, books, tasks, projects, skills, career, run, … templates/_macros.html — shared Jinja macros (metric_table, task_check). templates/reader.html — standalone markdown file browser. static/app.js — tab navigation, local project forms, runner grids + output dialog, Today capture/brain forms, data-map-query Workspace map deep links. workspace_content.py — read-only file access for /workspace-file/… and live artifact rows; imports scope/privacy rules from visual-second-brain/refresh-index.py. static/fonts/ — self-hosted Inter variable + JetBrains Mono (OFL); @font-face at top of style.css. static/metrics.js — read-only server operations controller: polling, host selection, history, workload filters, logs. metrics.py — local project checks, Linux/Windows host normalization, bounded historical queries. server_activity.py — container/process/service workloads, actual target probes, Loki activity and coverage. static/style.css — all styles; design tokens as CSS vars in :root (--accent, --green, …). static/manifest.webmanifest, static/icon-*.png — home-screen install; opens /#today. launchd/com.cloudtransition.dashboard.plist — always-on loopback server for phone access. DESIGN.md — visual design rationale (Orizuru); read before styling work.
