Phone access (dashboard-app CLAUDE.md): launchd keeps uvicorn on [IP_ADDRESS]:8000 while the USB drive is mounted; tailscale serve --bg --https=443 http://[IP_ADDRESS]:8000 publishes to tailnet only (not Funnel) at https://roosevelts-macbook-air.tail9aa23.ts.net/; phone needs Tailscale app signed in to same account, then Share → Add to Home Screen. Every tailnet device can trigger Run buttons, including claude --permission-mode acceptEdits, so keep the tailnet to your own devices. Install/restart/remove commands are in the plist header; logs: ~/.local-routines/dashboard/. After editing app.py: launchctl kickstart -k gui/$(id -u)/com.cloudtransition.dashboard. Stop phone access: tailscale serve --https=443 off; status: tailscale serve status. Gotchas: POST /api/tasks/toggle and POST /api/capture require header X-Requested-With: XMLHttpRequest (CSRF guard) and write through _atomic_write under _FILE_WRITE_LOCK — don't simplify. Toggle sends task text with line number; capture shifts later lines in TASKS.md so the server follows text to its new line and returns 409 when ambiguous; routine uses the same atomic writer but accepts checkboxes only in routine.md Weekly Review section; render checkboxes with task_check macro (carries data-text). #runOutputDialog lives in index.html outside tab panels — a modal inside a hidden panel opens at zero size. GET /api/file resolves paths and rejects anything outside workspace or off the extension allowlist; /api/file + /api/files (Reader, Run output) also refuse anything workspace_content.privacy_violation() flags: secret names, private/employer paths, work logs, College Planning — including deeper copies such as .trail/cache/College Planning/. Progress bars start transform: scaleX(0) and animate to data-width via animateBars() — setting width inline in a template breaks animation. OPENROUTEN_API_KEY/TYPESAFE_API_KEY come from process environment; app.py reads gitignored dashboard-app/.env at startup without overriding real env vars; after adding a key restart the LaunchAgent so server re-reads it — shell-spawned runs inherit server environment, so a key only in shell rc is not visible to them. Card context_files are inlined into the prompt only for OpenRouter (chat API cannot read files); Claude/Codex/OpenCode read locally; inlining skips out-of-workspace and privacy-flagged paths, bounded by CONTEXT_MAX_FILE_CHARS (80,000) / CONTEXT_MAX_CHARS (160,000).
