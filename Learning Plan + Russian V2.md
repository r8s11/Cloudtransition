# 52-Week Learning Plan for Working Professionals

> Balancing Full-Stack Cloud DevOps + Russian Language Learning

**Your Context:** Full-time worker with limited spare time
**Time Commitment:** 10-15 hours/week total (realistic for sustainability)
**Goal:** Consistent progress with weekly deliverables, no burnout

---

## 🎯 Philosophy: Sustainable Learning

### Core Principles
1. **Quality over quantity** - 10 focused hours beats 20 distracted hours
2. **Weekly wins** - Something tangible every week
3. **Parallel learning** - Tech & Russian don't compete, they complement
4. **Flexibility** - Life happens; adjust without guilt
5. **Compound progress** - Small consistent steps = massive results

### Weekly Time Budget (10-15 hours)
```
Tech Learning:     6-8 hours  (weekdays 1hr + weekend 3-4hrs)
Russian:           3-4 hours  (daily 20-30min)
Reading:           1-2 hours  (commute/before bed)
Buffer:            1 hour     (for catching up)
```

```jsx
function Counter() {

      border: '2px solid blue', 
      padding: '20px', 
      margin: '20px',
      borderRadius: '10px'
    }}>

      </button>
      <button onClick={() => setCount(count - 1)}>
```

**React: Build a Task List (40 min)**

Create `src/TaskList.jsx`:
```jsx
import { useState } from 'react';

function TaskList() {
  const [tasks, setTasks] = useState([
    { id: 1, text: 'Learn React', done: false },
    { id: 2, text: 'Learn SQL', done: false }
  ]);
  const [input, setInput] = useState('');
  
  const addTask = () => {
    if (input.trim()) {
      const newTask = {
        id: Date.now(),
        text: input,
        done: false
      };
      setTasks([...tasks, newTask]);
      setInput('');
    }
  };
  
  const toggleTask = (id) => {
    setTasks(tasks.map(task => 
      task.id === id ? { ...task, done: !task.done } : task
    ));
  };
  
  const deleteTask = (id) => {
    setTasks(tasks.filter(task => task.id !== id));
  };
  
  return (
    <div style={{ maxWidth: '500px', margin: '20px auto' }}>
      <h2>My Tasks</h2>
      
      <div>
        <input
          type="text"
          value={input}
          onChange={(e) => setInput(e.target.value)}
          onKeyPress={(e) => e.key === 'Enter' && addTask()}
          placeholder="Add a task..."
          style={{ padding: '10px', width: '70%' }}
        />
        <button onClick={addTask} style={{ padding: '10px', marginLeft: '5px' }}>
          Add
        </button>
      </div>
      
      <ul style={{ listStyle: 'none', padding: 0 }}>
        {tasks.map(task => (
          <li key={task.id} style={{ 
            padding: '10px', 
            margin: '10px 0',
            border: '1px solid #ddd',
            display: 'flex',
            justifyContent: 'space-between',
            alignItems: 'center'
          }}>
            <span
              onClick={() => toggleTask(task.id)}
              style={{
                textDecoration: task.done ? 'line-through' : 'none',
                cursor: 'pointer'
              }}
            >
              {task.text}
            </span>
            <button onClick={() => deleteTask(task.id)}>Delete</button>
          </li>
        ))}
      </ul>
    </div>
  );
}

export default TaskList;
```

```jsx
import { useState } from 'react';
import './App.css';

function App() {
  const [tasks, setTasks] = useState([]);
  const [input, setInput] = useState('');
  const [category, setCategory] = useState('Personal');
  
  const addTask = () => {
    if (input.trim()) {
      setTasks([...tasks, {
        id: Date.now(),
        text: input,
        category: category,
        done: false,
        createdAt: new Date().toLocaleDateString()
      }]);
      setInput('');
    }
  };
  
  const stats = {
    total: tasks.length,
    completed: tasks.filter(t => t.done).length,
    pending: tasks.filter(t => !t.done).length
  };
  
  return (
    <div className="app">
      <header>
        <h1>📋 Week 1 Task Manager</h1>
        <p>Built with React by [Your Name]</p>
      </header>
      
      <div className="stats">
        <div>Total: {stats.total}</div>
        <div>Completed: {stats.completed}</div>
        <div>Pending: {stats.pending}</div>
      </div>
      
      <div className="add-task">
        <input
          value={input}
          onChange={(e) => setInput(e.target.value)}
          onKeyPress={(e) => e.key === 'Enter' && addTask()}
          placeholder="What needs to be done?"
        />
        <select value={category} onChange={(e) => setCategory(e.target.value)}>
          <option>Personal</option>
          <option>Work</option>
          <option>Learning</option>
        </select>
        <button onClick={addTask}>Add</button>
      </div>
      
      <div className="task-list">
        {tasks.length === 0 ? (
          <p className="empty">No tasks yet. Add one above!</p>
        ) : (
          tasks.map(task => (
            <div key={task.id} className={`task ${task.done ? 'done' : ''}`}>
              <input
                type="checkbox"
                checked={task.done}
                onChange={() => {
                  setTasks(tasks.map(t =>
                    t.id === task.id ? {...t, done: !t.done} : t
                  ));
                }}
              />
              <div className="task-content">
                <span>{task.text}</span>
                <small>{task.category} • {task.createdAt}</small>
              </div>
              <button onClick={() => setTasks(tasks.filter(t => t.id !== task.id))}>
                Delete
              </button>
            </div>
          ))
        )}
      </div>
    </div>
  );
}

export default App;
```
