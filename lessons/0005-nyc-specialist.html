Time: 7 minutes · Win: turn official data into a narrow, sourced specialist

Pick one slice first

“NYC specialist” is too broad for one reliable tool. Start with a slice such as recent 311 request records, then add transportation, city services, or neighborhood references as separate vetted sources. NYC publishes an API guide and a 311 dataset with a queryable endpoint. NYC Open Data API guide · 311 dataset

A narrow, typed query

Use validated choices, a fixed endpoint, a short field list, and a hard row limit. Do not ask the model to write arbitrary query text.

from datetime import datetime, timezone
from typing import Annotated, Literal

import httpx
from pydantic import BaseModel, Field
from pydantic_ai import Agent, RunContext

Borough = Literal[
    "BRONX", "BROOKLYN", "MANHATTAN", "QUEENS", "STATEN ISLAND"
]

class CityEvidence(BaseModel):
    source_url: str
    retrieved_at: datetime
    rows: list[dict[str, str | None]]

nyc_agent = Agent(
    "openai:gpt-6.1-sol",
    deps_type=httpx.AsyncClient,
    instructions=(
        "Answer only from returned city data. Cite its source_url and "
        "retrieved_at. Do not infer legal rules or causes from 311 counts."
    ),
)

@nyc_agent.tool
async def recent_311(
    ctx: RunContext[httpx.AsyncClient],
    borough: Borough,
    limit: Annotated[int, Field(ge=1, le=10)] = 5,
) -> CityEvidence:
    """Fetch a small sample of recent NYC 311 records for one borough."""
    dataset_url = (
        "https://data.cityofnewyork.us/Social-Services/"
        "311-Service-Requests-from-2020-to-Present/erm2-nwe9"
    )
    response = await ctx.deps.get(
        "https://data.cityofnewyork.us/resource/erm2-nwe9.json",
        params={
            "$select": "created_date,complaint_type,status,agency,borough",
            "$where": f"borough = '{borough}'",
            "$order": "created_date DESC",
            "$limit": limit,
        },
    )
    response.raise_for_status()
    return CityEvidence(
        source_url=dataset_url,
        retrieved_at=datetime.now(timezone.utc),
        rows=response.json(),
    )

The borough is a fixed Literal, so user text cannot become arbitrary query syntax. Confirm field names and dataset update notes before relying on the sample. The city's data API is described by Socrata's endpoint docs.

Make evidence part of the output

  
For a production specialist, return a Pydantic model with an answer, source URL, retrieval time, and caveats. A validated model guarantees shape—not that a citation is real or supports the claim. Test citation membership and date handling in application code.

  
A 311 record reports a service request. It does not by itself establish city policy, legal rights, or what caused a neighborhood trend. Add the official source that owns each kind of answer.


  
Self-check

  

    Can the agent claim a building-code rule from 311 complaint counts?
    
No. Counts are not the authority for legal requirements. Retrieve the relevant official code or city guidance, cite it, and state its date and limits.
