Type and spacing

Use Inter for headings and body, with native system fallbacks when unavailable. Use JetBrains Mono only for commands and measured values. No font network requests. Body text: 16–18 px, line height 1.6, measure at most 72 characters. Use an 8 px spacing scale, 24–64 px page gutters, and 32 px between sections.

Identity and logo

No verified logo asset is registered for these artifacts. Use the text name “CloudTransition”; do not invent a logo or reuse an employer logo. Preserve factual sources and dates. Label examples and assumptions.

Layout and export

One continuous sheet, left-aligned text, clear headings, numbered steps only for real sequences. No glass panels, decorative charts, or perpetual motion. State must remain clear without color. Verify keyboard focus, narrow-screen overflow, and the final print layout.
