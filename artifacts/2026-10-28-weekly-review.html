Weekly workspace review

A reusable review sheet based on routine.md. This is a checklist, not a claim that this week’s work is complete.

  1. Review the work log.

    Capture what was learned, fixed, or repeated. Keep employer-sensitive details in the private playbook, not the shared memory index.

  2. Refresh active tasks.

    Use TASKS.md and DASHBOARD.md. Preserve dates and evidence; do not infer progress from an old plan.

  3. Choose one build.

    Follow the existing alternating project rhythm. Confirm that the selected project exists before resuming it.

  4. Find one automation candidate.

    Prefer a repeated manual step from the work log. A recommendation is not authorization to execute it.

  5. Park feedback, then close.

    Save a short principle for the relevant skill. Apply changes only after review. Keep the next action and its source path.

Source: routine.md, weekly review and working rhythm. Brand book. Artifact inbox.
