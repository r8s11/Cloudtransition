## How to Use This Plan

- **Strategic vs. tactical.** This file is the strategic spine. Day-to-day course deadlines live in **per-course trackers** (e.g., `College Planning/eng190-tracker.md`). Weekly tasks live in `TASKS.md`.
- **Roadmap depth lives elsewhere.** The book lists, LinkedIn Learning courses, YouTube channels, and lab specs are all in the curriculum reference at [regeneron-cloud-devops-roadmap_2.md](regeneron-cloud-devops-roadmap_2.md). This file is the calendar; that file is the curriculum.
- **Re-evaluate at each term boundary.** End of each 8-week term: confirm next term's course, adjust roadmap pace if the prior term ran hot or cold, and update the "Avg hrs/wk" column.
- **Term breaks are leverage.** SNHU's 8-week terms have ~1-week gaps between them. Those gaps are when lab work fits — not during weeks with assignments due.
