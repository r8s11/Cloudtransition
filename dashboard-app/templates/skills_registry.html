Skill registry

Skills OpenCode 2.3 registers for runs started at the workspace root, and what each agent's OpenCode rules let its model load. Read-only: nothing here edits a skill or an agent, and nothing is assigned.

A skill grants nothing. Loading a skill only adds its text to the conversation. Every tool the skill mentions (files, shell, web) still follows the agent's own permission rules. Whether the model may load a skill is decided by the agent's OpenCode skill rules, the last matching rule wins.

Those rules gate the model's skill tool only: OpenCode's explicit activation API loaded a skill the agent's rules deny (checked 2026-11-17), so skill rules are not an access boundary for whoever drives OpenCode.
