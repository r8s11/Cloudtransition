## Morning Routine (Weekdays, 6:00–7:15 AM)

```
6:00  Wake up, water, stretch (5 min)
6:05  Duolingo Russian (10 min)
6:15  Reading — 1 section of current book (20 min)
6:35  Review today's focus + calendar (5 min)
6:40  Get ready for work
7:15  Leave for work
```

> The morning block is about consistency, not intensity. 35 minutes of reading + Russian daily = 4+ hours/week of passive growth.

---

## Evening Routine (Weekdays, 9:00–9:30 PM)

```
9:00  Commit any code from tonight's session
9:05  2-sentence journal note (what I did, what I learned)
9:10  Prep tomorrow's clothes / bag
9:15  Wind down — no screens (read fiction, stretch, etc.)
9:30  Lights out target
```

## Rules

1. **Morning routine is non-negotiable** — even if evening doesn't happen, mornings compound.
2. **Tuesday is Sophia night** — this is how you graduate faster and cheaper.
3. **Thursday is building, not learning** — ship something, no matter how small.
4. **No context-switching mid-block** — React time is React time, Sophia time is Sophia time.
5. **15 min reading counts** — keep the streak going even on tired nights.
6. **Friday is optional** — use it or rest. No guilt.
7. **Saturday is the power block** — guard it from social commitments.
8. **Sophia courses count double** — Python on Sophia = Python for projects. Don't treat them as separate.
9. **Track hours honestly** — the dashboard works only if the data is real.
10. **Rest is productive** — burnout kills more plans than laziness.
