## Section 3: Skills Probe

**Q: "Walk me through what you've done in PowerShell."**

A: Standard admin scripting — AD user provisioning with `Get-ADUser`/`New-ADUser`/`Set-ADUser`, bulk operations from CSV with `Import-Csv | ForEach-Object`, group membership management with `Add-ADGroupMember`, M365 admin via Microsoft Graph and MSOnline modules — license assignments, mailbox stats with `Get-MailboxStatistics`, network checks with `Test-NetConnection`, remote execution with `Invoke-Command`. Not a script-developer level, but solid for sysadmin work and actively going deeper.

---

**Q: "What's your Linux experience?"**

A: Comfortable, not specialist. Production exposure across roles — managing Linux servers as part of broader systems work. Day-to-day: `systemctl`, `journalctl`, SSH key management, file permissions, basic shell scripting in Bash, log triage with `grep`/`awk`. I'd be transparent that my deepest expertise is on the Windows side.

---

**Q: "What about Azure?"**

A: AZ-900 certified, AZ-204 currently in progress. Hands-on with Entra ID / Azure AD across multiple tenants — user lifecycle, conditional access, MFA. I've worked with Azure compute and networking at the admin level — not architect-level. Studying SC-900 next to deepen the security side.

---

**Q: "What EDR tools have you used?"**

A: Cortex XDR at Jounce — alert investigation, endpoint isolation when needed. Microsoft Defender for Endpoint across multiple roles — daily monitoring, response. Plus baseline AV across the fleet.

---

**Q: "What firewalls / network gear have you worked with?"**

A: FortiGate at Jounce — VPN admin, troubleshooting, rule changes. Cisco Meraki dashboards — site-to-site VPN, switch and AP config, network monitoring. Solid fundamentals on routing, subnetting, common ports, DNS.

---

**Q: "Tell me about your scripting beyond PowerShell."**

A: Bash for Linux admin — log parsing, automated checks, cron jobs. Currently building Python — the AZ-204 path I'm on overlaps with Python tooling, and I'm working on portfolio projects. Strong on the IT operations side; intentionally building toward more developer-style automation.
