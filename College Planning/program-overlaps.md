## Program Switch Impact Analysis

If you switch FROM your current CS AS, here's what transfers and what you lose:

### CS AS → CS BS (natural continuation)

- **Transfers**: Everything (AS feeds directly into BS)
- **Lost**: Nothing
- **Additional**: ~60 more credits of upper-level CS + electives
- **Note**: This is the designed pathway per your current enrollment

### CS AS → IT BS

| What Transfers | What Doesn't |
|----------------|-------------|
| All Gen Ed (12 cr) | CS-210/217 (OOP) → would count as elective only |
| IT-140 Python (if taken) | CS-218/300 (Data Structures) → elective only |
| IT-145 Java (if taken) | CS-230 (Operating Platforms) → elective only |
| DAD-220/CS-231 Databases (if taken) | CS-250 (SDLC) → elective only |
| Free electives (6 cr) | CS-255 (System Analysis) → elective only |
| MAT courses → electives | CS-320 (Testing) → elective only |

**Verdict**: Most CS major courses become electives in IT, not wasted but not fulfilling IT requirements either. You'd need to take IT-200, IT-202, IT-212, IT-272, IT-313, IT-423, etc. from scratch.

### CS AS → Cybersecurity BS

| What Transfers | What Doesn't |
|----------------|-------------|
| All Gen Ed (12 cr) | Most CS courses → electives only |
| IT-140 Python | CS-230, CS-250, CS-255, CS-320 → electives |
| DAD-220 Databases (if taken) | Math beyond MAT-240 → electives |
| Free electives (6 cr) | |

**Verdict**: Cybersecurity shares the least with CS. You'd need CYB-200, 210, 220, 250, 260, 300, 310, 320, 400, 410, 420 — almost the entire major is new coursework.

### CS AS → Data Analytics BS

| What Transfers | What Doesn't |
|----------------|-------------|
| All Gen Ed (12 cr) | Most CS courses → electives |
| IT-140 Python | Programming beyond Python → electives |
| DAD-220 Databases (if taken) | Math except MAT-243 → electives |

**Verdict**: Data Analytics is the most different. Nearly all DAT-specific courses are new.

**The overlap between majors is low.** Gen Ed transfers perfectly (100%), but major courses are largely unique to each program. This means:

1. **Switching programs costs you time** — major courses don't transfer well between programs
2. **Your current CS AS path is the right one to commit to** if you want CS BS
3. **The earlier you decide, the less waste** — every CS-specific course you take is sunk if you switch
