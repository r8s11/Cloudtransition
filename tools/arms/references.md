## Principles

- Existing source files remain authoritative. An index locates facts; it does not certify freshness.
- Prefer a short source-linked answer over an uncited summary.
- A practical learning block produces an artifact; preserve the workspace's tutorial-first approach.
- Never invent personal preferences, project completion, usage history, or financial outcomes.

## Controlled variation

For a request for ten creative ideas, produce eight grounded in relevant references and two explicitly labeled wildcards. This ratio applies to ideation, not facts, compliance checks, schedules or safety decisions. Explain which reference each grounded idea uses. Add a successful wildcard to this library only after the user selects it; preserve the date and rationale.
